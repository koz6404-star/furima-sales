# Claude Code 用 プロジェクト指示

**このプロジェクトを Claude Code で開いた場合、必ずこのファイルを参照すること。**

---

## 言語指示（必須）

- **すべて日本語で会話すること**
- **英語での応答は禁止する**
- ユーザーへの返答、コメント、ドキュメント、ログメッセージを含め、日本語のみを使用すること
- 技術用語（API、script など）も可能な限り日本語で表現するか、必要な場合のみカタカナ・英語を併記すること

---

## プロジェクト概要

- Next.js フリマ売上・在庫管理アプリ
- Amazon SP-API 連携（売上・手数料・在庫）
- 再設計フェーズ進行中（取得・整形のアプリ外分離）

---
