# Phase7 売上在庫結合 実装概要

## 前提（Phase6 仮合格）

- **SKU結合ロジックは未検証**（FBA在庫データ0件のため）
- FBA在庫が流入した段階で結合率検証を再実施すること

---

## 1. 実装概要

- 売上一覧 API で `amazon_inventory_current` を LEFT JOIN 相当のロジックで付与
- `fulfillment_type = 'FBA'` かつ `sku` がある行のみ在庫結合
- 売上一覧画面に「在庫」列を追加し、表示ルールに従って表示

---

## 2. 在庫表示ルール

| 条件 | 表示 | スタイル |
|------|------|----------|
| 結合成功 かつ 在庫 > 0 | 数値 | 通常 |
| 結合成功 かつ 在庫 = 0 | 0 | 薄赤背景・ハイライト（在庫切れ） |
| 結合失敗 / 在庫未取得 | 取得なし | グレー文字 |

**結合失敗**の例：
- `fulfillment_type` が FBM（FBA 在庫 API に存在しない）
- `sku` が null
- `amazon_inventory_current` に該当 SKU が無い（未同期・販売済削除等）

---

## 3. 結合失敗時の表示仕様

- **表示文言**: 「取得なし」
- **ツールチップ**: 「FBM/未取得」（FBM の場合は FBA 在庫対象外、FBA の場合は在庫未取得）
- null ではなく必ず文字列で表示し、画面崩れを防ぐ

---

## 4. 変更ファイル

| ファイル | 内容 |
|----------|------|
| `src/app/api/amazon-sales-lines/route.ts` | FBA 行の SKU 一覧で `amazon_inventory_current` を取得し、`current_available` を付与 |
| `src/components/amazon-sales-list-client.tsx` | 在庫列追加、表示ルール（数値 / 0 ハイライト / 取得なし） |

---

## 5. 検証項目（FBA在庫0件時）

- [x] 売上一覧が表示される
- [x] 在庫列が表示される
- [x] 全行「取得なし」で表示される（FBA 在庫0件のため）
- [x] 0在庫ハイライトのスタイルが適用できる（結合成功時）

---

## 6. FBA在庫データ流入後に再検証すべき項目一覧

| 項目 | 確認方法 |
|------|----------|
| SKU結合率 | `GET /api/amazon-phase6-sku-match` で joined / notJoined / ratePercent を確認 |
| 結合成功時の数値表示 | 売上一覧で在庫数が数値で表示されることを確認 |
| 0在庫ハイライト | 在庫0の行が薄赤背景で表示されることを確認 |
| 結合失敗時の表示 | FBM 行・該当無し SKU で「取得なし」と表示されることを確認 |
| 再transform 後の安定性 | FBA在庫同期 → 売上一覧表示が正常に更新されることを確認 |
