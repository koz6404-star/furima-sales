# Amazon クライアントIDとシークレットの取得手順（初心者向け）

**SELLING_PARTNER_APP_CLIENT_ID** と **SELLING_PARTNER_APP_CLIENT_SECRET** の2つを取得する方法です。

※ リフレッシュトークンはお持ちとのことなので、この2つだけ追加すればOKです。

---

## 用語

| 用語 | 意味 |
|------|------|
| **セラーセントラル** | Amazon 出品者用の管理画面。ここにログインします。 |
| **開発者コンソール** | アプリ（API連携）を作成・管理する画面。セラーセントラルの中にあります。 |
| **LWA クライアント ID** | = SELLING_PARTNER_APP_CLIENT_ID。アプリを識別するIDです。 |
| **LWA クライアントシークレット** | = SELLING_PARTNER_APP_CLIENT_SECRET。アプリのパスワードのようなものです。 |

---

## ステップ 1：開発者コンソールを開く

1. **ブラウザ**（Chrome や Edge など）を開く
2. 次のリンクをクリックするか、アドレスバーに貼り付けて Enter を押す：
   ```
   https://sellercentral.amazon.co.jp/sellingpartner/developerconsole
   ```
3. **セラーセントラルにログイン**する（Amazon 出品者用のメールアドレスとパスワード）

※ 出品者アカウントがない場合は、この手順はできません。

---

## ステップ 2：既存のアプリがあるか確認する

リフレッシュトークンが既にある場合、**過去に作成したアプリ**がある可能性があります。

1. 開発者コンソールの画面に、**アプリの一覧**が表示されます
2. 「フリマ売上管理」や「Amazon 売上」など、自分で作ったアプリの名前を探す
3. **アプリ名をクリック**して、そのアプリの詳細を開く

### アプリが見つかった場合（ステップ 3-A へ）

→ 既存アプリから ID とシークレットを取得します。

### アプリが見つからない場合（ステップ 3-B へ）

→ 新しくアプリを作成します。

---

## ステップ 3-A：既存アプリから取得する

1. アプリの詳細ページが開いたら、**「認証情報を管理」** や **「Credentials」** といったボタン・リンクを探してクリックする
2. 画面上に次の2つが表示されます：
   - **LWA クライアント ID**（`amzn1.application-oa2-client.xxxxx` のような文字列）
   - **LWA クライアントシークレット**（`amzn1.oa2-cs.v1.xxxxx` のような文字列）
3. それぞれを**コピー**して、メモ帳などに貼り付けて控えておく
4. （シークレットは「表示」ボタンを押さないと見えないことがあります）

これで取得完了です。**ステップ 4** に進んでください。

---

## ステップ 3-B：新しくアプリを作成する

既存アプリがない場合、新規で作成します。

### 3-B-1. 「アプリを追加」をクリック

開発者コンソールの画面で、**「アプリを追加」** または **「Add new app client」** というボタンをクリックします。

### 3-B-2. 必要な項目を入力する

次のように入力します。

| 入力欄 | 入力する内容 |
|--------|--------------|
| **アプリ名** | 例：`フリマ売上管理`（わかりやすい名前なら何でもOK） |
| **OAuth ログイン URI** | `https://localhost` |
| **OAuth リダイレクト URI** | `https://localhost/callback` |

※ コピー＆ペーストで大丈夫です。

### 3-B-3. 作成してからIDとシークレットを控える

1. **「保存」** や **「追加」** をクリックしてアプリを作成する
2. 作成後、画面に表示される **LWA クライアント ID** と **LWA クライアントシークレット** をコピーして控える
3. シークレットは**最初にしか表示されない**ことが多いので、必ずその場で控えてください

---

## ステップ 4：.env.local に追加する

1. **Cursor** でプロジェクトを開く
2. 左側のエクスプローラーで **`.env.local`** を開く
3. 次の2行を追加する（`xxxxx` の部分を、控えた実際の値に置き換える）：

```
SELLING_PARTNER_APP_CLIENT_ID=amzn1.application-oa2-client.xxxxx
SELLING_PARTNER_APP_CLIENT_SECRET=amzn1.oa2-cs.v1.xxxxx
```

4. **保存**する（Ctrl + S）

※ `AMAZON_REFRESH_TOKEN` は既に入っているので、そのままにして大丈夫です。

---

## ステップ 5：アプリを再起動する

1. ターミナルで動いている `npm run dev` を **Ctrl + C** で止める
2. もう一度 `npm run dev` を実行する
3. ブラウザで「Amazon売上」→「Amazon同期（過去3ヶ月）」を試す

---

## まとめ

| やること | どこで |
|----------|--------|
| 開発者コンソールを開く | ブラウザで https://sellercentral.amazon.co.jp/sellingpartner/developerconsole |
| ID・シークレットを取得 | 既存アプリの「認証情報を管理」か、新規アプリ作成後 |
| .env.local に追加 | Cursor で .env.local を開いて2行追加 |
| アプリ再起動 | ターミナルで Ctrl+C → `npm run dev` |

---

## うまくいかない場合

- **開発者コンソールにアクセスできない**：出品者アカウントでログインしているか確認してください。
- **「認証情報を管理」が見つからない**：画面レイアウトが変わっている可能性があります。アプリをクリックして詳細を開いたら、「Credentials」「認証情報」「設定」などの項目を探してください。
- **新規アプリを作成した場合**：リフレッシュトークンは**その新しいアプリ用に再取得**する必要があります。既存のリフレッシュトークンは古いアプリ用なので、`scripts/get-amazon-refresh-token.mjs` の手順で再度取得してください。
