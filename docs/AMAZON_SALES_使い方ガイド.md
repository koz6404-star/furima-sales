# Amazon 売上明細 利用手順ガイド（初心者向け）

既にフリマアプリが動いており、Supabase・Amazon SP-API の設定も済んでいる前提です。

---

## 用語の説明

| 用語 | 意味 |
|------|------|
| **ターミナル** | コマンド（文字の命令）を入力して実行する窓。Cursor や VS Code に内蔵されています。 |
| **マイグレーション** | データベースに新しい表（テーブル）を追加する作業。ここでは Amazon 売上を保存するための表を作ります。 |
| **npm run ○○** | プロジェクト内の決まった処理を実行するコマンド。 |

---

## ターミナルを開く（コマンドを打つ場所）

コマンドは **ターミナル** で実行します。

### Cursor または VS Code を使っている場合

1. 画面上部のメニューから **「表示」** をクリック
2. **「ターミナル」** をクリック  
   または、キーボードで **Ctrl + `**（Ctrl キーと、Shift を押さない状態の @ のキー）を押す
3. 画面の下か横に、黒い（または白い）窓が開きます。これがターミナルです。

### それ以外の場合（エディタを使っていない場合）

1. Windows のスタートメニューを開く
2. 「PowerShell」または「コマンドプロンプト」と入力して起動
3. 開いた窓がターミナルです。

---

## やること：2ステップ

---

## ステップ 1：マイグレーションの実行

**マイグレーション**＝データベースに「Amazon 売上を保存する表」を追加する作業です。初回だけ必要です。

### 1-1. ターミナルを開く

上記の方法で、ターミナルを開きます。

### 1-2. プロジェクトのフォルダに移動する

ターミナルに、次のコマンドを **そのまま** コピー＆ペーストして、Enter キーを押します。

```
cd "D:\カーサープロジェクト\フリマアプリ　売上管理アプリ作成"
```

※ `cd` は「このフォルダに移動する」という意味です。

### 1-3. マイグレーションを実行する

次に、このコマンドを入力して Enter を押します。

```
npm run supabase-migrate
```

※ 「データベースに必要な表を作成する」という意味の処理が実行されます。

### 1-4. 結果を確認する

**うまくいった場合：**
```
Supabase へ接続しました。
  実行中: 021_amazon_orders_raw.sql
  実行中: 022_amazon_sales_lines.sql
2 件のマイグレーションを適用しました。
```
→ この場合は **ステップ 2** に進んでください。

**「すべて適用済み」と出た場合：**
```
すべてのマイグレーションは既に適用済みです。
```
→ 表はすでに作成済みです。**ステップ 2** に進んでください。

**エラーが出た場合：**
- 「接続情報が設定されていません」→ `.env.local` に `SUPABASE_DB_PASSWORD` が必要です。詳しくはトラブル時を参照。
- その他のエラー → 出たメッセージをそのまま控えて、サポートに相談してください。

## ステップ 2：アプリを起動して Amazon 売上を使う

### 2-1. アプリを起動する

**ターミナル**（ステップ 1 で使ったのと同じ窓）で、次のコマンドを入力して Enter を押します。

```
npm run dev
```

※ まだプロジェクトフォルダにいない場合は、先にステップ 1-2 の `cd` コマンドを実行してください。

**うまくいった場合：**
```
▲ Next.js 16.x.x
- Local: http://localhost:3000
```
のように表示されます。この表示が出たら、アプリが起動しています。

※ **このターミナルの窓は閉れず、そのままにしてください。** 閉じるとアプリが止まります。

### 2-2. ブラウザでアプリを開く

1. **ブラウザ**（Chrome、Edge、Firefox など）を開く
2. 画面の上の **アドレスバー**（URL を入力する欄）をクリック
3. 次のアドレスを入力して Enter を押す：  
   `http://localhost:3000`

※ アプリの画面が表示されます。

### 2-3. ログインする

- すでにアカウントがある場合：メールアドレスとパスワードを入力してログイン
- まだの場合：サインアップで新規登録してからログイン

### 2-4. 「Amazon売上」のページを開く

1. ログイン後、**画面上部** に「ホーム」「商品一覧」「完売一覧」などのリンクが並んでいます（これを **ナビ** といいます）
2. その中にある **「Amazon売上」** をクリック
3. Amazon 売上明細のページが開きます

### 2-5. データを取得する（同期）

1. 「Amazon売上」のページが開いたら、上部にあるオレンジ色のボタン **「Amazon同期（過去3ヶ月）」** をクリック
2. 「同期中…」と表示されます。数十秒〜1分ほどかかることがあります
3. 完了すると「注文: ○件、商品行: ○件…」のようなメッセージが表示され、一覧に売上データが出ます

## まとめ：何をどこでやるか

| やること | どこで | 具体的な操作 |
|----------|--------|--------------|
| マイグレーション | **ターミナル**（Cursor の「表示」→「ターミナル」で開く） | `cd "D:\...\"` でフォルダ移動 → `npm run supabase-migrate` を実行 |
| アプリ起動 | **ターミナル**（同じ窓） | `npm run dev` を実行。窓は閉じない |
| アプリを開く | **ブラウザ**（Chrome など） | アドレスバーに `http://localhost:3000` と入力 |
| 売上を見る | **ブラウザ**（アプリの画面） | ログイン → ナビの「Amazon売上」をクリック |
| データ取得 | **ブラウザ**（Amazon売上ページ） | 「Amazon同期（過去3ヶ月）」ボタンをクリック |

---

## トラブル時

| 症状 | 対処 |
|------|------|
| ターミナルがどこかわからない | Cursor のメニュー「表示」→「ターミナル」。またはキーボードで Ctrl + ` |
| 接続エラー（マイグレーション） | `.env.local` に `SUPABASE_DB_PASSWORD` を追加する必要があります |
| 「Amazon SP-API credentials missing」 | `.env.local` に Amazon 用の 3 つの設定が入っているか確認 |
| データが表示されない | ①マイグレーション実行したか ②「Amazon同期」ボタンを押したか ③同期した期間に Amazon で注文があったか |
